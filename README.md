# 🛒 Nexus Market

**Nexus Market** es una plataforma de e-commerce desarrollada con **Django 6.0**, enfocada en una gestión de inventarios eficiente y una interfaz de usuario limpia y responsiva.

## 🚀 Características actuales
- **Gestión de Productos**: CRUD completo a través del panel de administración de Django.
- **Catálogo Visual**: Interfaz dinámica que consume datos de la base de datos en tiempo real.
- **Diseño Responsivo**: Implementación de Bootstrap para una visualización óptima en cualquier dispositivo.
- **Manejo de Media**: Configuración de almacenamiento de imágenes para productos.

## 🛠️ Stack Tecnológico
- **Lenguaje**: Python 3.14
- **Framework**: Django 6.0.4
- **Base de Datos**: SQLite3 (Desarrollo)
- **Frontend**: HTML5, Bootstrap 5.3
- **Procesamiento de Imágenes**: Pillow
